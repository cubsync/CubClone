## 下载

- `CubClone-0.7.0-arm64-v8a.apk` —— 绝大多数手机用这个
- `CubClone-0.7.0-universal.apk` —— 32 位设备，或不确定机型架构时用

列出与操作分身需要 Root 或 Shizuku（shell 权限）。

## 新增

- **批量删除分身**：一次列出所有空间的分身，每行带数据体积，可搜索、按空间筛选、
  按空间/体积/名称排序；「仅无数据」只勾没有数据的空壳，进页面不预选任何人。
- **批量备份可以一次选多个空间**：主空间 + 任意几个分身一起备份。
- 备份范围可选：应用数据、设备数据、安装包（可按空间各存一份）、权限，
  外加 Android/data、obb、media 三块外部目录（默认不勾）。
- 恢复时可选恢复到哪个空间、恢复哪些内容。
- 内置 zstd：同样数据约比 gzip 快 5 倍，默认 3 档。

## 修复

- 对话框（含「恢复选项」）跟随应用内的深浅色设置，不再出现白底浅字或黑底黑字。
- 分身里的应用打开数据库报错、界面一直转圈（共享存储属主问题）。
- 批量删除页的体积不再每次打开都全盘扫，10 分钟内复用上次结果；
  排序菜单里新增「重新统计体积」。

## 注意

- 批量删除**不可撤销**：勾了有数据的分身，会连数据一起删。
- 体积数字取自系统同一接口，与「设置 → 应用信息 → 存储」一致；
  统计和删除都不需要 root，只有 Shizuku 也能用。

## Download

- `CubClone-0.7.0-arm64-v8a.apk` — for nearly all phones
- `CubClone-0.7.0-universal.apk` — for 32-bit devices, or if unsure about the ABI

Root or Shizuku is required to list and operate on clones.

## New

- **Batch delete clones**: lists every clone across all spaces with its data size;
  search, filter by space, sort by space/size/name. "No data only" ticks just the empty
  shells, and nothing is pre-selected when the page opens.
- **Batch backup can cover several spaces at once**: main space plus any clones.
- Backup scope is selectable: app data, device data, APK (optionally one copy per space),
  permissions, plus Android/data, obb and media (off by default).
- Restore lets you choose the target space and which parts to restore.
- Bundled zstd: about 5x faster than gzip on the same data, level 3 by default.

## Fixed

- Dialogs (including restore options) now follow the app's own light/dark setting instead
  of producing light text on white or dark text on black.
- Apps inside clones failing to open their database and spinning forever (shared storage
  ownership issue).
- The batch delete page no longer rescans everything on every open; results are reused
  for 10 minutes, with "Recount sizes" in the sort menu.

## Notes

- Batch delete is **irreversible**: ticking a clone with data deletes that data too.
- Sizes come from the same system interface that Settings uses, so the numbers match
  "App info → Storage". Neither counting nor deleting requires root; Shizuku alone works.
